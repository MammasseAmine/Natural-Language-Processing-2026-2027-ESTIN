Conditional Random Fields (CRF)

Every feature votes, the best sequence wins
1 · Why is HMM not enough?

In the previous course we used HMMs to tag sequences, and they work. But on real text, three problems come back again and again:

Limited features

An HMM only looks at the word itself. It cannot easily ask: “Is the word capitalized? Does it end in -ing? Is the previous word Mr.?” These clues are gold for labeling, and HMM cannot use them.

Wrong question

HMM is generative: it models how the sentence was “created”, P(words, tags). But we never need to generate sentences. We only need to choose tags for a sentence we already have.

Words are treated alone

HMM assumes each word depends only on its own tag. Real language breaks this rule. In “I deposited money in the bank”, the word money tells us bank is a financial place, HMM cannot use that neighbor.

The key idea of CRF

Stop modeling how sentences are made. Model only what we need: P(tags | words), the probability of a tag sequence given the sentence. And let the model use any feature of the input we can imagine.

2 · Two Families of Models

This is the deepest difference between HMM and CRF. Click each side to compare.

Models the joint probability, P(X, Y)

A generative model learns the full “story” of the data: how tags produce words. It could, in theory, generate new sentences with tags.

  • Analogy: to recognize cats vs. dogs, you learn to draw a perfect cat and a perfect dog, then check which drawing matches the photo.
  • Examples: HMM, Naive Bayes
  • Cost: it must model the words too, a hard, wasteful job.

Models the conditional probability, P(Y | X)

A discriminative model skips the story. It learns only the boundary between answers: given this sentence, which tag sequence is best?

  • Analogy: to recognize cats vs. dogs, you learn the differences directly, pointy ears, whiskers, without ever learning to draw.
  • Examples: CRF, Logistic Regression, most neural networks
  • Gain: the input X is given, so we can use unlimited features of it, for free.
Remember this pair

Naive Bayes → Logistic Regression is the same jump as HMM → CRF. Same task, but the discriminative model conditions on the input instead of generating it. A linear-chain CRF is often called the “sequence version of logistic regression.”

3 · What is a CRF?

A Conditional Random Field is a discriminative model for labeling sequences. The version used in NLP almost all the time is the linear-chain CRF:

① No arrows

The edges are undirected, no “who generates whom.” We only score how well tags fit together and fit the sentence.

② Tags see everything

Each tag yᵢ is connected to the entire input X, not just to its own word. Any feature of the whole sentence can help decide any tag.

③ Why “linear chain”?

Tags connect only to their direct neighbors (yᵢ₋₁ ↔ yᵢ). This keeps exact inference fast, Viterbi still works! General CRFs allow any graph, but NLP uses the chain 99% of the time.

4 · One Formula to Understand

This formula looks scary, but it has only five parts. Click each colored part to see what it means.

P(y|x) = 1/Z(x) · exp(Σᵢ Σₖ λₖ fₖ(yᵢ₋₁, yᵢ, x, i))

Click any colored part of the formula

Waiting for your click…

The score of a sequence

The inner part Σ λₖ·fₖ is just a weighted sum of features , exactly like logistic regression. A tag sequence that fires many good features (high λ) gets a high score.

From score to probability

exp() makes all scores positive. Z(x) divides by the total over all possible tag sequences, so probabilities sum to 1. Z is computed with the forward algorithm, we never list all sequences.

What you just saw

No single feature decides. All features vote with their weights, at every position, and transition features tie the positions together, so the best full sequence wins, not each word alone.

7 · The Secret Weapon: Global Normalization

Before CRFs, another discriminative model existed: the MEMM. It normalized probabilities at each word separately, and this created the famous label bias problem: states with few outgoing options “win” unfairly, and the model can ignore the actual words.

Local normalization (MEMM)

Each position must give out a full probability of 1, no matter what. A bad path can still look “confident” at every step → label bias.

Global normalization (CRF)

Only one division, by Z(x), over the whole sequence. Complete paths compete fairly against each other → no label bias.

Global normalization is the central innovation of CRFs over MEMMs.

8 · How Do We Train and Use It?

Training, find the λ's

  • Goal: maximize the log-likelihood of the correct tags in the training data.
  • The objective is convex → gradient methods (L-BFGS, SGD) find the global optimum.
  • Each gradient step needs Z(x) → computed by the forward algorithm in O(n·T²).

Decoding, find the best tags

  • There are T² possible tag sequences, far too many to list.
  • Because tags only link to their neighbors, dynamic programming works.
  • The Viterbi algorithm finds the best path in O(n·T²), same friend as in HMMs.
9 · Strengths and Weaknesses

Strengths

  • Discriminative, answers the right question, P(Y|X)
  • Unlimited, overlapping features of the input
  • No label bias, global sequence optimization
  • Solid theory, convex training
  • Long-time state of the art for NER, POS, chunking

Weaknesses

  • Training is slow, forward pass at every step
  • Humans must design the features by hand
  • Millions of features → large memory use
  • Hard to scale to very large tag sets
10 · Are CRFs Dead in the Deep Learning Era?

Absolutely not! CRFs changed jobs: they became the final layer of neural networks for sequence labeling. The famous combination is BiLSTM-CRF (or BERT-CRF):

The network replaces the humans

The BiLSTM or Transformer reads the sentence and builds rich vectors for each word , these replace the hand-made feature functions.

The CRF keeps the structure

The CRF layer learns a transition matrix between labels (e.g. I-PER cannot follow B-LOC in BIO tagging) and picks the best full sequence with Viterbi.

Trained together

The whole stack is trained end-to-end to maximize the CRF log-likelihood , deep features + global sequence reasoning in one model.

Key Takeaway

A CRF asks the right question, P(tags | words), and answers it with a weighted sum of simple features, normalized once over the whole sequence. That gives it rich features, no label bias, and the best full tag sequence via Viterbi. Even today, a CRF layer sits on top of BiLSTM and BERT models, adding structure that pure neural networks miss.
