Tokenization

Turning text into pieces a computer can understand
What is Tokenization?

Tokenization is the process of breaking a text into smaller pieces called tokens. These tokens can be words, sentences, characters, or even subwords – depending on what we need.

It is usually the first step in any NLP pipeline because computers can't understand raw text directly. They need to work with numbers, and tokenization is how we turn text into something a computer can process.

Example

Input: "I love Natural Language Processing."

Tokens: I love Natural Language Processing .

Why is Tokenization Important?

Breaks text into pieces

Turns long text into small, manageable units.

Helps analysis

Makes it easier to extract features and patterns.

Works with ML models

Needed for models like BERT and GPT to learn.

Improves search

Makes searching and indexing text much better.

Word Tokenization

Word tokenization splits text into individual words. It's the simplest and most common approach.

Sentence:

"John studies NLP every day."

Word Tokens:

["John", "studies", "NLP", "every", "day", "."]

Advantages

  • Simple and easy to understand
  • Easy to implement
  • Works well for many languages

Disadvantages

  • Very large vocabulary
  • Can't handle new words well
  • OOV problem: new words become [UNK]

Common Use Cases

Simple spam detection, keyword extraction (SEO), basic sentiment analysis, and traditional bag-of-words models.

Sentence Tokenization

Input:

Hello students. Welcome to NLP. Today we study tokenization.

Output:

["Hello students.", "Welcome to NLP.", "Today we study tokenization."]

This is also called Sentence Boundary Detection (SBD).

Advantages

  • Preserves context and full meaning
  • Great for tasks like translation & summarization
  • Helps in analyzing grammar and syntax

Disadvantages

  • Hard to handle ambiguous punctuation (e.g., "Dr.", "U.S.")
  • Too broad for deep word-level analysis
  • Struggles with informal text lacking proper punctuation

Common Use Cases

Machine translation (translating document sentence-by-sentence), text summarization, and breaking up long documents for easier processing.

Character Tokenization

Word:

"NLP"

Character Tokens:

["N", "L", "P"]

Benefits

  • No out-of-vocabulary problem
  • Handles misspellings well

Drawbacks

  • Very long sequences
  • More expensive to compute

Common Use Cases

Spell checkers, analyzing DNA/protein sequences, extracting text from blurry images (OCR), and processing languages without spaces (like Chinese).

Subword Tokenization

Modern NLP systems use subword tokenization to get the best of both word-level and character-level approaches. It splits words into smaller meaningful pieces.

Word:

"unhappiness"

Subword Tokens:

["un", "happi", "ness"]

Subword methods reduce vocabulary size while still handling unknown words.

Common Use Cases

Modern Large Language Models (LLMs). This is the industry standard used to train AI like ChatGPT, BERT, Claude, and LLaMA because it handles multiple languages and complex words perfectly.

Byte Pair Encoding (BPE)

BPE is one of the most popular tokenization methods used in modern language models like GPT.

How it works:

  1. Start with individual characters
  2. Count how often each pair of characters appears in the training data
  3. Merge the most frequent pair into a single new token
  4. Repeat until you reach the target vocabulary size
l o w   →   l o w e r   →   n e w e s t

Frequent pair: "e s"   →   "es"

WordPiece Tokenization

WordPiece was created by Google and is used in BERT.

Word:

"playing"

Tokens:

["play", "##ing"]

The ## symbol means the token continues the word.

SentencePiece

SentencePiece is a language-independent tokenizer from Google. It treats text as a raw stream of characters, including spaces. Spaces are replaced by a special symbol (_).

Examples:

English: "Hello world"
Tokens: ["_Hello", "_world"]

Special Tokens & Vocabulary

Beyond normal words, tokenizers use special tokens that carry structural meaning. These tokens help models understand the shape and purpose of the input.

Token Role Used In
[CLS] / <s> Start of sequence; its embedding is used for classification BERT / RoBERTa
[SEP] / </s> Separator between segments; end of sequence BERT
[PAD] Fills short sequences to the same length; ignored by attention All models
[MASK] Target for prediction in masked language modeling BERT
[UNK] Fallback for words not in the vocabulary Word / WordPiece
<|endoftext|> Document boundary in generative training GPT

Common Bug

Mismatched special tokens are a top source of silent failures. Always pair a model with its own tokenizer – using the wrong [CLS] placement or chat template quietly wrecks performance.

From Tokens to Numbers (Encoding & Decoding)

Neural networks cannot read text; they only understand math. Because of this, every token must be mapped to a unique integer ID using a Vocabulary (a giant lookup dictionary).

The Vocabulary (Lookup Table)

[PAD] → 0 [UNK] → 1 I → 104 love → 305 NLP → 891 . → 9

* Modern models have vocabularies with 30,000 to over 100,000 unique token IDs.

1. Encoding (Text → IDs)

How we prepare text for the AI model.

1. Text: "I love NLP."
2. Tokens: ["I", "love", "NLP", "."]
3. IDs: [104, 305, 891, 9]

2. Decoding (IDs → Text)

How the AI model replies to us.

1. AI Predicts: [104, 305, 891]
2. Tokens: ["I", "love", "NLP"]
3. Text: "I love NLP"
Summary
  • Tokenization converts text into tokens – the first step in any NLP system.
  • Common approaches: sentence, word, character, and subword tokenization.
  • BPE, WordPiece, and SentencePiece are the modern standards.
  • Subword tokenization balances vocabulary size and handling of unknown words.
  • Special tokens like [CLS], [SEP], [PAD], and [UNK] carry structural meaning.
  • Tokenization directly impacts model performance – choose wisely!
