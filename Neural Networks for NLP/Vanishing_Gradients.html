Vanishing Gradients

When the signal dies on the way back
The question of this course

Two networks read the same sentences. The shallow one learns in minutes. The deep one trains for hours and still guesses almost randomly on long sentences. Nothing is broken. The code is correct. So what stops it?

Training loss: 3 layers vs 30 layers

The deep network is not overfitting. It never even fits the training data. The learning signal never reaches its first layers.

Where the gradient comes from

A network learns by asking one question at every weight: if I change this number a little, how much does the error change? That answer is the gradient. It is computed at the output, where the error lives, and then carried backwards, layer by layer, by the chain rule.

The chain rule turns "backwards" into a product. To reach layer 1 in a 20-layer network, the gradient must pass through 19 multiplications. Click any part below.

∂L/∂hL × JL × JL−1 × … × J2 = ∂L/∂h1
Each J is one layer's local slope – how much that layer changes its input.

If every J is a bit smaller than 1, the product shrinks towards zero. If every J is a bit bigger than 1, it blows up. Only a very narrow band in between keeps the signal alive across many layers. Deep networks live or die on that number.

With skip connections the gradient also takes a direct route that multiplies by 1. The product can no longer collapse – it only drifts slowly, and normalisation keeps that drift under control.

The book numbers come out of the same formula: at γ = 0.5, ten layers leave 0.510 ≈ 0.00098, and twenty layers leave 0.520 ≈ 0.00000095. The first layers get an update roughly a million times smaller than the last ones. They are frozen in practice.

Why γ is usually below 1

γ is not chosen by anyone. It comes out of two things multiplied together: the slope of the activation function and the size of the weights. Classic activation functions have a slope that is almost never 1.

The weights matter too

In a recurrent network the same weight matrix W is reused at every time step, so the backward pass multiplies by W again and again. What decides the outcome is the largest singular value of W, written λ:

λ < 1

Every step shrinks the signal. After 50 steps it is gone: the gradient vanishes.

λ ≈ 1

The signal keeps its size. This is the razor's edge that everything else tries to reach.

λ > 1

Every step amplifies. The gradient explodes and the weights turn into NaN.

This is why the starting values of the weights are not a detail. Xavier and He initialisation exist for exactly one reason: to place λ near 1 on day one, so that training has a chance to begin.

Imagine shining a light through a stack of slightly dark glass panes. Each pane takes only a little. After enough panes, nothing comes out the other side. Backpropagation works the same way: press play and follow the pulse from the error back to the first layer.

The visible damage

No long-range grammar

Agreement, pronouns and negation that sit far from the verb are simply missed.

Weak language models

Next-word prediction leans on the last few words only, so perplexity stops improving.

Poor translation

Word order and gender in the target language depend on context the model never kept.

Long documents fail

Accuracy falls as inputs grow, so summarising or answering over a full document breaks down.

The other failure: exploding gradients

Same product, opposite direction. One problem hides, the other screams.

Vanishing

  • Gradients → 0
  • Early layers never learn
  • Loss flattens at a bad value
  • The historical blocker of deep nets
  • Hard to spot – no error message

Exploding

  • Gradients → ∞
  • Weights become NaN or Inf
  • Training crashes right away
  • Rarer, but obvious
  • Simple fix: gradient clipping

Clipping rescales the gradient when its norm passes a threshold, so the direction is kept and only the step length is cut. There is no matching trick for vanishing: you cannot amplify a signal that is already zero – you have to change the architecture so it never disappears.

Why Transformers beat the problem

An RNN passes information from the first word to the last through every word in between. That is a path of N steps, so the gradient is multiplied N times. Self-attention connects every word to every other word directly. The path is one step, whatever the distance. Drag the slider.

Is this still a problem in 2026?

For most people building on Transformers: largely no. Residual connections, layer normalisation and attention's one-step path have made standard architectures safe. But the problem did not disappear – it moved. It still shows up in:

Very deep Transformers

Past roughly 100 layers, careless initialisation brings the decay back.

Streaming recurrent models

Architectures built for linear-time or real-time inference return to a sequential path.

State-space models

In Mamba and S4 the long-range gradient path has to be designed on purpose, not assumed.

Neural ODEs

When depth becomes continuous, stability of the backward flow is an explicit design problem.

The lesson outlived the architecture: whenever information has to travel a long way inside a model, someone has to guarantee the gradient can travel back.

Key takeaway

Backpropagation multiplies. Numbers slightly below 1, multiplied enough times, become zero – and a layer with a zero gradient does not learn, no matter how long you train. Every serious advance in deep learning for language, from LSTM gates to residual blocks to attention, is a different answer to the same question: how do we keep the learning signal alive on its way back?
